## 집필 상태

본편 계획은 120화다. 지금 읽을 수 있는 실제 원고는 1~10화이며 **11~120화와 외전 8화는 아직 원고를 작성하지 않았다.** 계획 문서를 완성 원고로 집계하지 않는다. 기존 `arcs/`는 집필 설계이며 이 폴더의 `chapters/`와 구분한다.

각 화는 첫날의 연속된 이야기다. 10화는 1부의 끝이며 작품 전체의 결말이 아니다. 시간 규칙·인물의 기억·가족관계를 유지해 새로 쓴 산문이다.
