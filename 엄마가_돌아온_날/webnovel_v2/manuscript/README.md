## 집필 상태

본편 계획은 120화다. 실제 본문은 20화까지이며 **21~120화와 외전 8화는 아직 집필하지 않았다.** 다음 집필 회차는 21화다. 20화는 2부의 끝이지 작품 전체의 결말이 아니다.

이 폴더의 `chapters/`가 읽기용 원고다. 상위 `arcs/`와 기획 문서는 설계이므로 본문 분량에 포함하지 않는다. 회차·글자 수·내용 식별값은 `publication.json`에서 확인할 수 있다.
