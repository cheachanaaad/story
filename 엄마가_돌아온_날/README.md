# 엄마가 돌아온 날

> 죽은 엄마가 돌아왔다. 그런데 내 딸이 사라졌다.

## 전체 이야기를 먼저 읽으려면

[15. 전체 회차 12화 구성](15_전체회차_12화_구성.md)에 1화부터 12화까지의 주요 진행과 결말을 정리했다. 표의 각 제목을 누르면 `episodes/`의 개별 화 문서로 이동한다. 각 화에는 주요 사건, 인물·관계 변화, 마지막 장면, 다음 화로 이어지는 이유가 들어 있다.

## 작품의 중심

전 세계가 10년 전으로 돌아간다. 두 시점에 모두 살아 있던 사람은 미래의 기억을 가져오지만, 그동안 죽었던 사람은 과거의 기억으로 살아 있고, 그동안 태어난 아이는 존재하지 않는다. 기록 복구 엔지니어 한도윤은 5년 전에 잃은 엄마와 다시 통화한다. 그리고 일곱 살 딸의 사진이 휴대폰에서 사라졌다는 사실을 깨닫는다.

원래 시간으로 복귀할 기회가 발견된다. 그러나 한 사람만 돌아갈 수는 없다. 딸을 되찾는 일과 살아 있는 엄마를 지키는 일이 양립하지 않는다는 사실 앞에서, 가족들은 서로의 상실을 대신 결정하려 했던 자신을 마주한다.

## 문서 상태

- 문서 묶음 버전: 1.1 / 작성·갱신일: 2026-09-19. 시간 규칙과 공통 정본 데이터는 기존 1.0을 유지한다.
- 단계: 결말까지 연결한 창작 설계와 회차별 트리트먼트 초안. 완성 소설이나 완성 촬영 대본은 아니다.
- 구성: 12화 완결 초안. 기존 12개 서사 단위 U01–U12를 각 1화로 배치하고 48개 핵심 장면 S01–S48을 유지한다. 최종 매체·화별 분량은 제작 단계에서 정한다.
- 이 문서들은 사용자와 나눈 설정을 토대로 작성했다. 인물 이름·날짜·복귀 원리·조연·세부 사건·결말은 창작 설계에서 채택한 초안이며, 사용자가 이미 모든 세부를 승인했다는 뜻은 아니다.
- 시간 현상과 실험 장치는 허구다. 실제 과학으로 실현 가능하거나 검증된 현상이라고 주장하지 않는다.
- 아래 문서는 결말을 포함한다.

## 설정의 중심축

원래 시점은 **2036-09-19 06:00**, 되돌아간 시점은 **2026-09-19 06:00**이다. 모두 한국 표준시로 표기한다. 원래 세계는 복귀 목표로 보존되고, 10년 전 세계는 14일 동안 진행된다. 복귀가 성립하면 원래 세계의 바로 그 시점이 재개된다. 과거에서 10년을 빨리 감는 방식이 아니다.

엄마는 원래 세계에서 2031년에 사망했다. 딸은 2029년에 태어났다. 따라서 엄마의 과거와 딸의 현재를 한 세계에 임의로 합치는 해결은 허용하지 않는다. 원래 세계로 돌아가는 경로와, 과거에 남아 바뀐 미래를 살아가는 경로는 구별한다.

## 초안 결말

전 세계 복귀는 성립한다. 한도윤과 윤서진은 딸 한하린과 재회한다. 이정희는 원래 세계에서 여전히 사망한 상태이며, 과거에서 새로 만든 물건이나 녹음은 따라오지 않는다. 원래 세계에 있던 기존 기록이 모두 사라지는 것은 아니다. 부모에게 남은 기억으로 엄마가 전해 달라고 한 말을 딸에게 이야기한다. 복귀를 반대했던 사람들의 상실도 함께 남긴다. 모든 사람에게 같은 의미의 행복한 결말은 아니다.

## 사용할 때

전체 이야기는 15를 먼저 읽는다. 집필할 때는 02·03·04·07·09를 확인한 뒤 해당 `episodes/` 문서와 11의 S번호를 함께 읽는다. 회차 문서는 기존 규칙과 결말을 확장하는 하위 집필 자료이며 상위 정본을 덮어쓰지 않는다. 새 설정을 만들기 전에 12의 검토 항목과 13의 변경 규칙을 적용한다. 복귀 규칙과 인물의 지식 상태를 감동을 위해 임의로 바꾸지 않는다.

기존 공통 구조 검증은 이 폴더에서 `python tools/validate_story.py`로 실행한다. 자동 검증은 데이터와 참조의 일치만 확인하며 작품성·서사적 완전성·모든 회차 산문의 의미 일치를 보증하지 않는다.
