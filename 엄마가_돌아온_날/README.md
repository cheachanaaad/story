# 엄마가 돌아온 날

> 죽은 엄마가 돌아왔다. 그런데 내 딸이 사라졌다.

## 현재 집필 기준: 장편 웹소설 v2

**[웹소설 v2 안내](webnovel_v2/README.md)를 먼저 읽는다. 본편 120화 + 외전 8화의 장편 설계다.**

기존 12화는 큰 줄거리를 정리한 초기 트리트먼트였다. 사용자의 장편 웹소설 요청을 반영하여, 기록실의 개별 의뢰·허위 재회 사업·귀환 원본 조사·가족의 정보 은폐·살아 있는 사람의 증언·현장 검증과 운영·귀환 이후 생활을 연결한 120화 구성을 작성했다. 각 부에 10화씩 있으며 매화의 시각, 선행 원인, 목표와 장애물, 세부 진행, 성과와 대가, 관계·정보 변화, 끝 장면, 후속 회수가 들어 있다.

**현재 읽는 경로:** [전체 연재 설계](webnovel_v2/00_연재설계.md) → [18명 인물·10개 장기 사건선](webnovel_v2/01_인물과_장기사건선.md) → [시간·정보·복선 장부](webnovel_v2/02_시간정보_복선장부.md) → [회차 문서 안내](webnovel_v2/README.md) → [외전 8화](webnovel_v2/13_외전_8화.md) → [집필 검수](webnovel_v2/14_집필검수.md).

본편 각 화 4,500–5,500자, 외전 각 화 4,000–5,000자를 작업 목표로 삼았다. 전체 목표는 공백 포함 57.2만–70만 자다. 이것은 완성 원고의 실제 분량이나 플랫폼 의무 기준이 아니다. **현재 저장한 것은 128편의 구체적인 사건 설계이며, 128편 전체의 완성 소설 원고는 아니다.**

## 정본을 구분하는 방법

시간 규칙 R01–R14, 주요 인물 7명의 생애, 336시간 창, 12개 거점, 귀환 성공과 정희·지우의 O 부재는 유지한다. v2의 회차 번호·세부 시각·추가 인물·정보 공개 순서는 `webnovel_v2/`를 적용한다. 아래 v1·v1.1의 S번호, `episodes/`, 15번 12화 구성은 **이전 판 참고 자료**이며 장편 집필의 회차 기준이 아니다. 이전 판을 삭제하거나 덮어쓰지 않았다.

세계의 물리 규칙을 바꾸려면 아래 02와 v2의 시간 장부·영향 회차를 같이 고친다. v2에 새로 추가한 인물·세부 사건·연재 분량은 이번 창작 설계에서 채택한 안이며, 사용자가 모든 세부를 이미 승인했다는 뜻은 아니다.

## 작품의 중심

전 세계가 10년 전으로 돌아간다. 두 시점에 모두 살아 있던 사람은 미래의 기억을 가져오지만, 그동안 죽었던 사람은 과거의 기억으로 살아 있고, 그동안 태어난 아이는 존재하지 않는다. 기록 복구 엔지니어 한도윤은 5년 전에 잃은 엄마와 다시 통화한다. 그리고 일곱 살 딸의 사진이 휴대폰에서 사라졌다는 사실을 깨닫는다.

원래 시간으로 복귀할 기회가 발견된다. 그러나 한 사람만 돌아갈 수는 없다. 딸을 되찾는 일과 살아 있는 엄마를 지키는 일이 양립하지 않는다는 사실 앞에서, 가족들은 서로의 상실을 대신 결정하려 했던 자신을 마주한다. 문식·지우의 가족은 같은 사건을 반대편에서 경험한다.

## 시간과 결말

원래 시점 O는 **2036-09-19 06:00**, 회귀 시작 B는 **2026-09-19 06:00**이다. 모두 한국 표준시다. 창은 336시간이며 **2026-10-03 06:00**에 닫힌다. 실제 전이는 **05:59:50**에 성립한다. B에서 10년을 빨리 감는 방식이 아니라 보존된 O의 시간이 재개된다.

정희는 O에서 2031년에 사망했고 하린은 2029년에 태어났다. 정희의 B와 하린의 O를 임의로 합칠 수 없다. 전 세계 복귀는 성립하고 도윤·서진은 하린과 재회한다. 정희·지우는 O에서 여전히 사망한 상태이며, B에서 새로 만든 사진·녹음·물건은 따라오지 않는다. O에 원래 남아 있던 옛 기록이 모두 사라지는 것은 아니다. 부모와 다른 생존자에게 남은 경험 기억으로 새 기록을 만든다. 반대했던 사람들의 상실은 결말에도 남는다.

시간 현상과 실험 장치는 허구다. 실제 과학으로 검증된 현상이나 실현 가능한 장치라고 주장하지 않는다. 문서에는 결말이 포함된다.
